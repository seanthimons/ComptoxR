# Agent instructions

## Specmill gaps go upstream

Wrappers are generated by Specmill from `apis/*.yml`. If Specmill can't
express a feature or can't match an existing wrapper's behaviour, open an
issue in [seanthimons/specmill](https://github.com/seanthimons/specmill) to
fix it there. Don't work around it locally with a hand-written wrapper, a
patched helper, or a change to `generic_request`.

Each issue should include:

- the ComptoxR wrapper and the operation it calls (method, path, schema file);
- what the old wrapper did, and what Specmill produces instead or can't produce;
- a minimal reproduction, with live or mocked inputs where possible.

Link the issue from the ComptoxR PR or issue it blocks. Leave the affected
wrappers on their current implementation until the fix is released and the
Specmill pin is updated.
