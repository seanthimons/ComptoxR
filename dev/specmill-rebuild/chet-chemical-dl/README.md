# CheT chemical download

New public binding `chemi_chet_chemicals_chemical_dl(body)` selects only
`GET /chemicals/chemical_DL`. It uses Specmill's native `.ct_request` and
schema validation. No existing public signature changes.

The canonical `schema/chemi-chet-prod.json` is unchanged. The reviewed subset
copies the selected GET operation, all its schema properties, `info`, and
relative `servers`. There are no `$ref` dependencies. `derive.py` reproduces
it. `provenance.json` records the hashes and exact omissions and corrections:

- OpenAPI 3.0.3 becomes 3.1.0, so Specmill can preserve the GET body.
- `requestBody.required: false` becomes `true`, matching the deployed service.

These are semantic corrections, not verbatim fields. Everything else in the
selected operation is preserved, including the declared binary response.
`deployed-source.json` and `retrieval.json` retain the official sourceURL,
retrieval time, status, content type and raw source hash. The existing
`chemi_burl` resolver supplies the production origin for `/api/chet`.

GET request bodies have undefined interoperability semantics in OpenAPI 3.1.
Specmill's warning is retained. Servers and intermediaries may reject them.
The named empty list `stats::setNames(list(), character())` serializes as `{}`;
use a named list for arbitrary nested object fields.

`live.R` performs only read-only GETs. `live.rds` retains actual status, media,
request body and raw response bytes. `live-summary.json` records CSV header,
record count, byte count and hash, and verifies the generated binding's decoded
CSV against the captured records. A successful status alone is insufficient.
The deployed CSV contains 4,028 six-column chemical records, then 30 single-field
`""` records. It is not uniformly rectangular. R read.csv skips that empty
trailer. The evidence records this limitation; the binding preserves the entire
response as text. The fixture copies the header, first two public chemical
records, and the complete 30-record empty trailer.
Native decoding returns text for `text/csv` and raw bytes for
`application/octet-stream`. It does not silently turn CSV into a table.

`portable-get-body.R` is the supplied generic v0.1.41 proof. It exercises a
self-contained validated client, GET `{}`, nested fields, rejection before
HTTP, the POST sibling on localhost only, and a fresh check. Its POST never
contacts production. The targeted package test additionally exercises the
actual selected binding, CSV/binary decoding and an HTTP 400.

The scoped `specmill.yml` selects the new service for full generation and
freshness without changing the parent root config, pin, helper or inventories.
The parent integration must register `apis/chemi-chet-chemical-dl-reviewed.yml`
in its own root service list and update its pin to the tested release. Do not
copy new generated bytes over an old ownership record. `verify.R` adopts only
the exact reviewed pre-generation NAMESPACE hash when it is unowned, then
regenerates with the released generator and runs a fresh check. It never
adopts a replaced wrapper or helper.
